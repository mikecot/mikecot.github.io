# Network Statistics Portal

Public analytics hub for Lava Network performance and adoption metrics.

![Stats Main Portal](/assets/images/blockchain-infrastructure/stats/stats-main-portal.png)

**Features:** Interactive world map, multi-chain analytics, provider health monitoring, real-time reporting

![Network Analytics Dashboard](/assets/images/blockchain-infrastructure/stats/stats-network-analytics.png)

## Public Analytics Hub

The Lava Stats platform serves as the primary public-facing analytics hub for the Lava Network, providing real-time insights into network performance, adoption metrics, and ecosystem growth. Built for transparency and community engagement.

## Advanced Visualization

- **Interactive World Map**: Global network activity and geographic distribution
- **Multi-Chain Analytics**: Cross-blockchain performance and usage patterns
- **Provider Health**: Real-time monitoring of decentralized infrastructure
- **Real-time Reporting**: Live data updates with sub-second refresh rates

**Link**: [stats.lavanet.xyz](https://stats.lavanet.xyz/)

**Stack:** Next.js 14, TypeScript, Chart.js, TimescaleDB, Redis, DragonflyDB, Kafka, pnpm, Bun, Docker, Docker Compose  
**Scale:** 500M+ monthly RPC requests, 2.5M+ daily active users, $2B+ TVL, 99.95% uptime
