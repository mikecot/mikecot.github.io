# Gateway Portal

Developer-first RPC gateway providing unified access to 30+ blockchain networks.

![Gateway Portal Dashboard](/assets/images/blockchain-infrastructure/gateway/gateway-portal-dashboard.png)

**Features:** Simple authentication, multi-chain access, basic usage analytics  
**Stack:** Next.js, React, TypeScript, Nx monorepo, TailwindCSS, Headless UI, Radix UI, multi-region deployment (EU/US), Google GCP, Amazon AWS  
**Deployment:** Multi-region hosting with geographic redundancy

## Technical Implementation

A straightforward RPC gateway built to provide developers with easy access to multiple blockchain networks. The implementation focuses on simplicity and reliability rather than fancy features - just a clean interface to connect to different chains without the usual hassle.

## Key Features

- **Multi-Chain Support**: Access to 30+ blockchain networks
- **Developer Experience**: Clean interface with basic analytics
- **Multi-Region Deployment**: EU and US regions for better latency
- **Reliable Performance**: Solid uptime with efficient operations
